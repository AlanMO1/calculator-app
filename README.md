calculator-app
A simple calculator app built in C++ with Qt.

Requirements
Qt 6 (with Widgets)
A C++ compiler (MinGW g++)

Build
qmake calculator.pro
mingw32-make

Run
./release/myapp.exe

Files
main.cpp: program entry point
autoresize.cpp / autoresize.h: calculator window and logic
calculator.pro: Qt project file
